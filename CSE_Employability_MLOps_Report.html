Objective

Build a reproducible end-to-end machine-learning workflow that uses student academic, technical-skill, and employability-related data to predict a student's Skill_Gap_Level. The notebook demonstrates the steps from dataset inspection and preprocessing to model selection, saved-model inference, API testing, container packaging, and CI/CD automation.

CI/CD workflow

  • Trigger: push or pull request to main, or manual workflow dispatch.
  • Continuous Integration (CI): check out the repository, set up Python, install dependencies, and run pytest -v.
  • Continuous Delivery step: after tests pass, build the Docker image and verify that it exists.
  • Dependency: the Docker job requires the test job to succeed, so a failed test prevents the Docker build job from running.

Interpretation and limitations

  • The reported performance reflects the supplied dataset and the specific train/test split in the notebook; it does not alone establish real-world generalization.
  • The class imbalance and comparatively low recall for the Low class warrant further investigation, for example with class-wise error analysis and additional validation.
  • The model predicts the target label present in the dataset. The validity of the resulting employability or skill-gap conclusions depends on how that label was defined and collected.
  • The CI/CD workflow builds and verifies a Docker image; the supplied workflow does not by itself deploy the application to a public hosting service.
